> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make both README files sufficient for a first-time user to configure `.env`, move the project to another computer, and avoid exposing API keys.

**Architecture:** Keep the current README structure and language switch links. Expand the existing environment sections in parallel; no application code or secret files change.
